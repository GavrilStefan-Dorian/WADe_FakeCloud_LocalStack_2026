What happens to the file?

Upload a CSV. Our local server puts the file in the selected emulator’s wade-graduates-in bucket. Open the S3 inspection panel to find that object.

Lambda runs automatically. S3 sends an ObjectCreated notification to wade-graduates-v1. It validates each record and calculates the totals.

Read the result. Lambda saves a JSON report in wade-graduates-out. Open the activity and inspection panels to see what was observed in each emulator.
