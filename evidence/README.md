# Recorded measurements

The CSV files are exploratory client-observed S3/Lambda measurements from the presentation machine, using warmed SDK clients. S3 GET follows PUT. They are not cold-start benchmarks, universal emulator rankings or comparisons with real AWS. Exact environment metadata was not recorded for every sample.

JSON reports are generated locally by `verify_pipeline.py`. Notification backups, session state and generated reports remain local and are ignored by Git.
